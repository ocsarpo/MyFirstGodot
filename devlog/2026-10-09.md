# 2026-10-09 - Day 4

오늘 목표는 Enemy가 Player를 자동으로 추적하게 만드는 것이었다. 동작 확인과 시행착오는 사용자의 실습 기록을, 최종 설정은 현재 프로젝트 파일을 기준으로 정리했다.

## 오늘 진행한 내용

1. `enemy.tscn`을 만들었다. CharacterBody2D 루트 아래 Sprite2D와 CollisionShape2D를 구성하고 `icon.svg`와 RectangleShape2D를 사용했다.
2. Enemy에 `enemy.gd`를 연결했다. 키보드 입력 대신 게임 로직이 방향과 속도를 계산하도록 했다.
3. `@export var target: Node2D`로 추적 대상을 노출하고 Main의 Enemy Instance에서 조작 가능한 Player를 지정했다.
4. `global_position`으로 월드 위치를 비교했다. `direction_to()`로 Player 방향을 구하고 `velocity = direction * speed`, `move_and_slide()`로 추적했다.
5. `target == null`이면 반환하여 대상이 지정되지 않은 프레임의 처리를 끝내도록 했다.
6. `distance_to()`로 거리를 확인하고 일정 거리 이내에서는 속도를 0으로 설정해 정지하도록 했다. Player가 멀어지면 추적을 재개하는 것을 확인했다.
7. 정지 거리를 100에서 120으로 조정했다. Node 중심 거리와 CollisionShape 경계 간 거리가 다름을 배웠다.
8. 정지 거리가 매직넘버인지 고민했다. 현재는 게임 느낌에 맞춰 조절하는 파라미터로 이해하고, Inspector 노출 등의 개선은 아이디어로 남겼다.

## 최종 파일 상태

- Enemy 속도는 `100.0`, 정지 거리는 `120.0`이다. `target`만 export 변수이며 정지 거리는 일반 변수다.
- 원본 Enemy에는 스크립트가 연결되어 있다. Main의 Enemy Instance는 Floating 모드이며 Target이 Player로 지정되어 있다.
- Main의 Player 위치는 `(466, 324)`, Enemy 위치는 `(143, 528)`이다.
- 문서 작업 과정에서 직접 만든 게임 코드와 Scene은 추가로 수정하지 않았다.

## 시행착오

### Inspector에 Target이 보이지 않음

`enemy.gd`를 작성했지만 Enemy Node의 Script 연결이 사라져 export Target이 보이지 않았다. 스크립트를 다시 연결해서 해결했다. 파일 생성과 Node 연결은 별도 작업임을 배웠다.

디스크 파일과 에디터 상태 관련 메시지가 있었고, 그 과정에서 이전 Scene 변경 일부가 사라진 것으로 추정했다. 정확한 원인은 확인되지 않았으므로 단정하지 않는다.

### 정지 거리 100에서 계속 밀어붙이는 느낌

100에서는 Enemy가 Player와 충돌한 뒤에도 계속 접근하려는 느낌이 있었다. `distance_to()`가 중심 간 거리라는 점과 CollisionShape 크기를 고려해 120으로 조정하니 자연스럽게 멈췄다. 이 값은 현재 크기에 맞춘 실습 파라미터다.

## 오늘의 핵심

**CharacterBody2D를 키보드 입력 대신 게임 로직으로 움직였다.**

```text
Target 참조 → 월드 위치 비교 → 거리 확인
→ 멀면 direction_to() → velocity 설정 → move_and_slide()
→ 가까우면 정지 → 다시 멀어지면 추적 재개
```

Node 참조와 export 설정, null 확인, 방향·거리 계산을 함께 사용했다. 거리 계산은 충돌 모양의 실제 간격과 다르며 정지 거리는 상황에 맞게 조절해야 한다.
