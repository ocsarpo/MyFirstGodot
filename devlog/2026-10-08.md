# 2026-10-08 - Day 3

오늘은 아이템 접촉으로 점수를 올리고, Signal을 통해 화면에 반영하는 흐름을 직접 만들었다. 실습 결과는 사용자 기록을, 최종 구조와 파일 이름은 현재 저장소를 기준으로 정리했다.

## 오늘 진행한 내용

1. `item.tscn`을 만들고 Area2D 루트 아래 Sprite2D와 CollisionShape2D를 배치했다. 외형은 `icon.svg`, 감지 범위는 RectangleShape2D를 사용했다.
2. Area2D의 `body_entered` Signal을 에디터에서 연결했다. 처음에는 들어온 body의 이름을 Output에 출력해 Player 접촉을 확인했다.
3. `queue_free()`로 Item 삭제를 예약했다. 루트가 삭제될 때 외형과 감지 영역도 함께 삭제되는 것을 배웠다.
4. Player에 `player` Group을 지정했다. `is_in_group()`으로 역할을 확인한 뒤에만 아이템을 처리하도록 했다.
5. Player 스크립트에 `score: int = 0`과 `collect_item()`을 추가했다. 아이템 접촉 시 Item이 해당 함수를 호출하고 점수를 1씩 올리도록 했다. 실제 스크립트 파일 이름은 `player.gd`가 아니라 `gdscript.gd`다.
6. 점수가 1, 2, 3으로 누적되는 것을 확인했다. 이후 사용자 정의 `score_changed(new_score: int)` Signal을 선언하고 `score_changed.emit(score)`로 변경된 점수를 알렸다.
7. Main에 CanvasLayer와 Label을 추가하고 초기 Text를 `Score: 0`으로 설정했다. 카메라가 움직여도 점수는 화면에 고정되도록 했다.
8. Main 루트에 `main.gd`를 연결했다. `_ready()`에서 Player의 Signal을 연결하고, 수신 함수가 Label.text를 갱신하도록 했다. 아이템을 먹을 때 화면 점수가 증가하는 것을 확인했다.
9. Item Scene 루트 이름을 Area2D에서 Item으로 바꾸었다. 기존 Instance 이름은 Area2D, Area2D2, Area2D3으로 남아 Main에서 직접 Item, Item2, Item3으로 정리했다.

## 최종 파일 상태

- Main의 Player Instance 이름은 `Player`, `DummyPlayer`다. 원본 `player.tscn` 루트 이름은 `CharacterBody2D`이며 `player` 그룹에 속한다.
- Main에는 `Item`, `Item2`, `Item3`, `Item4`의 네 Instance가 배치되어 있다.
- Item의 `body_entered`는 Scene 파일에서 연결하고, Player의 `score_changed`는 Main 코드에서 연결한다.
- Main의 점수 UI는 `Player`의 Signal을 수신한다.
- 기존 이동, 타일 맵, 사방 경계는 유지했다. 문서 정리 과정에서 게임 코드와 Scene을 추가로 수정하지 않았다.

## 오늘의 핵심

**이벤트 발생 → 게임 상태 변경 → UI 반영** 흐름을 처음 만들었다.

```text
Item 접촉 → body_entered → player 그룹 확인
→ collect_item() → score 증가 → score_changed
→ Main이 Label 갱신 → Item 삭제 예약
```

Area2D는 접촉을 감지하고, Group은 역할을 구분한다. Player는 상태를 관리하며 Signal로 변화를 알리고, Main이 UI를 연결한다. Scene 원본의 루트 이름과 이미 배치된 Instance 이름은 별개라는 점도 배웠다.
