# 2026-10-07 - Day 2

오늘 목표는 TileMapLayer / TileSet의 기본 구조를 이해하고, 타일에 Collision을 정의해 맵에 반복 배치하는 것이었다. 아래는 사용자의 직접 실습 기록과 저장된 프로젝트 파일을 기준으로 정리했다.

## 오늘 진행한 내용

1. `main.tscn`에 TileMapLayer를 추가했다. 기존 StaticBody2D 사방 경계는 그대로 유지했다.
2. TileMapLayer의 Tile Set에 새 TileSet Resource를 만들었다. 타일 정의와 실제 맵 배치가 다른 역할임을 배웠다.
3. Tile Size를 64×64로 설정했다. 실제 게임 그래픽보다 타일 구조 이해에 집중했다.
4. `icon.svg`를 Atlas Source의 텍스처로 등록하고 64×64 영역으로 타일을 정의했다. 정의한 타일을 맵의 여러 칸에 직접 배치했다.
5. TileSet에 Physics Layer 0을 추가했다. 물리 설정에서 F 키로 선택한 타일 전체를 덮는 사각형 Collision을 만들었다.
6. 직접 플레이하면서 Collision 없는 타일은 통과하고, Collision을 지정한 타일에는 막히는 차이를 확인했다.
7. Collision이 정의된 타일을 여러 위치에 더 배치했다. 별도의 StaticBody2D나 CollisionShape2D를 칸마다 만들지 않아도 같은 충돌 성질이 적용되는 것을 확인했다.

## 저장된 상태 확인

- TileSet과 Atlas Source는 `main.tscn` 내부 Resource로 저장되어 있다.
- Tile Size와 Atlas 텍스처 영역 크기는 모두 64×64다.
- Atlas에 네 타일이 정의되어 있고, `(1, 0)` 타일에 사각형 충돌 정보가 있다.
- TileMapLayer에 배치 데이터가 저장되어 있으며 기존 Player 두 개와 사방 벽 네 개도 유지되어 있다.
- 게임 코드나 Scene을 문서 정리 과정에서 추가로 수정하지 않았다.

## 짧은 소감

Scene·Collision·TileSet의 에디터 설정이 아직은 반복 작업처럼 느껴졌다. 다만 성질을 한 번 정의하고 여러 곳에서 재사용하면서 엔진이 반복 작업을 줄이는 방식도 익히고 있다.

## 오늘의 핵심

**TileSet에서 타일의 성질을 정의하고, TileMapLayer에서는 정의된 타일을 배치한다.**

- 보이는 타일이 반드시 충돌하는 것은 아니다.
- 타일별 Collision 정의를 여러 배치에서 재사용할 수 있다.
- 벽을 Node 하나하나로 구성하는 방식에서 타일 기반 맵 구성으로 넘어가기 시작했다.
