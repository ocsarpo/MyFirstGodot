# 2026-10-18 - Day 8

오늘 목표는 Player가 죽었다는 느낌을 시각적으로 강화하는 것이었다. 기존 Tween·await·Signal을 재사용해 패배 흐름에 연출을 붙였다. 실행 경험은 사용자 기록을, 구체적인 값과 순서는 현재 코드를 기준으로 정리했다.

## 오늘 진행한 내용

- Player의 `die()`에서 사망 상태와 이동 중단을 먼저 적용하고 Sprite2D만 Tween 대상으로 삼았다. 원래 크기의 2배로 0.1초 동안 확대한 뒤 0.25초 동안 0으로 축소한다. TRANS_SINE과 EASE_IN_OUT을 사용했다.
- `await tween.finished` 이후에 `died.emit()`을 호출하도록 바꿨다. Main은 Player 사망 연출이 끝난 뒤 GAME OVER를 표시한다.
- GAME OVER Label은 크기 0.5배, Alpha 0으로 시작한다. 0.2초 페이드 인 → 0.15초 동안 2배 확대 → 0.1초 동안 원래 크기 복귀를 순서대로 실행한다.
- `modulate.a`가 투명도이며 `"modulate:a"`를 Tween 속성 경로로 사용할 수 있음을 확인했다.
- `pivot_offset = size / 2`로 Label 자체의 중앙을 확대 기준점으로 설정했다. 이전 `self` 실수를 떠올리며 실제 Tween 대상을 확인했다.

## 현재 흐름

Enemy 충돌 → Player 사망 상태·이동 중단 → Sprite 확대·축소 → Tween 종료 → died Signal → Main의 GAME OVER 등장 연출로 연결된다. Main은 UI 연출 시작 시 Game Over 상태를 설정하므로 연출 중에도 R 재시작이 가능하다.

Player의 물리 본체는 축소하거나 삭제하지 않는다. 이번 코드 변경은 `player.gd`와 `main.gd`이며 Scene 변경은 없다. 문서 정리 과정에서 게임 코드를 추가로 수정하지 않았다.

## 오늘의 핵심

상태 변경은 즉시 적용하고, 외부 알림은 시각적 연출이 끝난 뒤 보낼 수 있다. Sprite2D와 Label을 대상으로 명확히 지정해 물리 동작과 표시를 나누고, Alpha와 pivot으로 등장 느낌을 조절했다.
