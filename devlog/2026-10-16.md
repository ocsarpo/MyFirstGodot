# 2026-10-16 - Day 7

오늘은 GAME OVER 이후 Restart로 한 판의 최소 루프를 완성하고, 아이템 획득과 득점에 시각적 피드백을 추가했다. 실행 경험은 사용자 기록을, 설정값과 배치는 현재 파일을 기준으로 정리했다.

## 오늘 진행한 내용

- Input Map에 `restart` Action과 R 키를 추가했다. Main의 `is_game_over`가 참일 때 `Input.is_action_just_pressed("restart")`를 확인하고 `get_tree().reload_current_scene()`으로 새 판을 시작했다. Player·점수·아이템·Enemy 위치와 Game Over 상태가 초기화되는 것을 확인했다.
- Item 획득 시 루트를 0.08초 동안 1.2배로 키우고 0.12초 동안 0으로 줄였다. `await tween.finished` 뒤 삭제하며, 연출 중 중복 획득은 `collected`로 막았다.
- 점수 갱신 때 Label을 1.4배로 키웠다가 원래 크기로 되돌렸다.
- Item Sprite2D에 1.08배 확대와 원래 크기 복귀를 반복하는 idle Tween을 추가했다. TRANS_SINE과 EASE_IN_OUT으로 부드럽게 변화시켰다.
- 각 Item이 0~0.6초의 랜덤 시차를 두도록 `randf_range()`, `create_timer()`, `await timeout`을 사용했다. 공통 스크립트 한 번의 수정으로 여러 Instance에 동작을 적용했다.
- 학습용 DummyPlayer와 기존 StaticBody2D 사방 벽 4개를 제거했다. Collision 타일을 가진 `Wall` TileMapLayer로 경계 구성을 시작했다. 기존 `TileMapLayer` Node는 남아 있지만 배치 데이터는 제거되어 있다.
- TileSet에서 Physics Layer 0의 타일 전체 Collision을 F 키로 지정하는 과정을 복습했다. 현재 Wall은 별도 TileSet의 `(0, 0)` 타일을 사용하며 회전도 적용되어 있다.
- Item을 21개로 늘렸다. Player는 `(14, 50)`, Enemy는 `(-483, 20)`에 배치되어 있다.
- Camera Limit을 비활성화했다. 이전 Limit 숫자는 파일에 남아 있다. 기본 viewport를 1280×720으로 설정하고 Camera Zoom은 `(0.6, 0.6)`으로 조절했다. CanvasLayer UI는 월드 카메라 Zoom과 독립적으로 표시한다.

## 시행착오: self로 Main 전체 확대

Item 코드를 Score Label에 복사하면서 Tween 대상의 `self`를 `label`로 바꾸지 않아 게임 전체가 커졌다 작아졌다. `self`는 현재 스크립트가 붙은 Node라는 점을 복습하고 실제 Label을 대상으로 수정했다.

## 10월 게임 진행 상황

이동·TileMap·아이템·점수·Enemy 추적과 충돌·사망·Game Over·Restart가 연결됐다. Item 획득, Score UI, Item idle 시각 연출도 추가했다. 기능 동작뿐 아니라 주요 행동이 전달되는 최소한의 피드백도 월 1게임 완성 기준으로 삼기로 했다.

다음 후보는 사망·Game Over·새 판 시작 연출, 그래픽 통일, 효과음, 맵 디자인 정리다. 이번에는 구현하지 않았다.

## 오늘의 핵심

```text
시작 → 이동·아이템 획득·점수와 시각 피드백
→ Enemy 충돌 → 사망 → GAME OVER
→ R 입력 → Scene Reload → 새 게임
```

한 판의 최소 루프가 닫혔고, 행동에 피드백을 주기 시작했다. Scene 재사용, Tween, 랜덤 시차, Camera Zoom과 타일 경계를 실제 게임에 적용했다.
