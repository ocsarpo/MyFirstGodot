# 2026-10-13 - Day 6

오늘 목표는 Enemy와 충돌하면 Player가 죽고 이동이 멈추며 GAME OVER가 표시되는 패배 조건을 만드는 것이었다. 실행 결과는 사용자의 실습 기록을, 최종 설정은 현재 파일을 기준으로 정리했다.

## 오늘 진행한 내용

1. Enemy의 `move_and_slide()` 이후 `get_slide_collision_count()`, `get_slide_collision(i)`, `get_collider()`로 Player와 충돌했는지 확인했다.
2. 충돌 테스트를 위해 정지 거리를 0으로 두었다. 최종 파일에서는 Enemy 코드 기본값이 `0.0`이고 Main의 기존 Instance 값 `300.0`은 제거되어 있다.
3. 접촉 중 로그가 매 물리 프레임 반복되는 현상을 확인했다. 충돌 감지가 한 번만 일어나는 것은 아님을 배웠다.
4. Player에 `is_dead`와 `die()`를 추가했다. 이미 죽었으면 반환하여 중복 사망 처리를 막고, 처음 죽을 때 속도를 0으로 만들었다.
5. Player의 `_physics_process()` 시작에서 사망 여부를 확인하도록 했다. 충돌 후 WASD와 방향키를 눌러도 이동하지 않는 것을 확인했다.
6. Enemy가 player 그룹을 확인한 뒤 로그 대신 `collider.die()`를 호출하도록 했다.
7. Player에 사용자 정의 `died` Signal을 추가하고 사망 처리 마지막에 발생시켰다. Main에서 Signal을 연결해 기존 점수 Label을 `GAME OVER`로 바꾸었다.
8. `$Player`는 클래스나 파일명이 아니라 현재 Node 기준 Scene Tree의 이름 경로이며, `get_node("Player")`의 축약이라는 점을 복습했다. `$CanvasLayer/Label`도 같은 방식이다.

## 함께 저장된 파일 변경

- `gdscript.gd`와 UID 파일이 `player.gd`와 UID 파일로 이름 변경되었고, Player Scene의 스크립트 경로도 변경되었다.
- 초기 실습용 `sprite_2d.gd`와 UID 파일은 삭제되었다.
- 문서 정리 과정에서 게임 코드와 Scene을 추가로 수정하지 않았다.

## 10월 게임 진행 상황

Player 이동, TileMap 기본, Item 획득과 Score, Enemy 추적과 충돌, Game Over까지 연결했다. 다음 학습 후보는 GAME OVER 이후 Restart이며 아직 구현하지 않았다.

## 오늘의 핵심

```text
Enemy와 충돌 → player 그룹 확인 → Player.die()
→ is_dead 설정·이동 중단 → died Signal
→ Main 수신 → GAME OVER 표시
```

반복되는 충돌은 상태값으로 중복 처리를 막는다. Player는 사망 상태를 관리하고 Main은 Signal을 받아 UI를 변경한다.
